# Napomene o bibliotekama u browser kodu

[BROWSER_THIRD_PARTY_NOTICES.txt](BROWSER_THIRD_PARTY_NOTICES.txt) čuva tekstove licenci i autorske napomene pronađenih npm biblioteka. [browser-packages.json](browser-packages.json) navodi tačne verzije i izvore. Spisak potiče iz JavaScript/CSS mapa referentnog build-a; pri promjeni zavisnosti ili ulaznih pack-ova ponoviti pregled i obnoviti napomene.

Za neke pakete izvorni npm paket sadrži samo izričitu MIT/ISC deklaraciju, bez zasebnog licencnog fajla. Ti slučajevi su označeni u zbirnom tekstu; priloženi su kanonski tekstovi dozvole iz SPDX i izvorno pripisivanje, bez izmišljanja copyright godina. Dodatna upstream napomena react-remove-scroll-bar ima svoj nepromjenjivi Git blob izvor; ne predstavlja se kao pronađena u nedostupnom objavljenom npm commitu.

Odjeljak axe-core uključuje MPL-2.0, njegove napomene trećih strana i vezu ka punom izvornom kodu tačne verzije. Decidim i Decidim Awesome zadržavaju svoje AGPL licence. Licence fontova, Leaflet-a, ikona i drugih statičnih asseta ostaju zasebne; za Source Sans Pro koji Decidim kopira u build sačuvana je [Adobe/OFL napomena](../fonts/SOURCE-SANS-PRO-OFL.txt).

Ove napomene ne mijenjaju softversku licencu projekta i nisu dozvola za korišćenje tuđeg brenda. Sačuvati ih uz kopije browser asseta i obezbijediti navedeni izvorni kod prema primjenjivim uslovima.
