# Porijeklo elemenata API dokumentacije

Slike `images/graphiql.png`, `images/graphiql-variables.png`, `images/graphiql-headers.png`, `images/menu.png` i `images/navbar.png` odgovaraju fajlovima paketa `graphql-docs` 5.2.0. To su primjeri iz tog paketa, a ne snimci građana ili naloga ove instalacije. Autorske napomene i MIT dozvola su sačuvani u [LICENSE.graphql-docs.txt](LICENSE.graphql-docs.txt).

Stil potiče iz generisane API dokumentacije i u ovom izvozu je prilagođen sistemskim fontovima. Ranije upakovani ProximaNova fajlovi i MyFonts poziv nisu uključeni jer pravo njihove redistribucije nije utvrđeno u ovoj pripremi. Ova napomena ne proširuje MIT dozvolu na izostavljene fontove.
